# Sparse coding and navigation study

The study asks whether representations with similar activity budgets create
different familiarity landscapes. It does not assume that spiking improves
accuracy, that colour always helps, or that a frozen insect-inspired encoder
outperforms pretrained deep networks.

The current priority is a working spiking navigation architecture, with spiking
treated as a design constraint. See [the autonomous navigation investigation](openloop-spiking.md)
for the updated hypotheses, prototypes and development observations. The wider
matrix below remains available for later controlled comparisons.

## Model and public interface

`VisualEncoder` accepts RGB or GB tensors `[B,C,H,W]` in `[0,1]`. Its ordinary
output is `[B,total_KCs]`; the default is binary activity over a presentation.
`diagnostics(..., record=True)` additionally returns PN/KC spike rasters
`[time,batch,neurons]`, per-neuron counts, first-spike times (infinity for silent
neurons), inhibitory traces, and explicit continuation state. State resets
between calls unless passed explicitly. The ordinary navigation interface always
resets it. Only flower fixation-sequence experiments may carry it forward.

The graded front end uses the existing hexagonal sampling, adaptation, contrast
and G/B opponency. This is not a spectral reconstruction of bee trichromatic
vision: RGB blue/green channels are proxies, and UV is absent.

The new circuit uses polarity-separated, RMS-normalized visual inputs, bounded
PN currents, excitatory sparse PN→KC connections, and ordinary LIF updates with
an exponential membrane decay. All thresholds, synapses and initial conditions
are fixed at test time. Wiring is generated by a private seeded generator;
inference contains no random sampling. Inhibition is a finite decaying state
driven by population spikes, not an exact top-k operation. Adaptation is a
decaying spike-triggered subtractive current. Each form/colour stream has its
own feedback state. These are explicit modelling assumptions.

The default LIF membrane time constant is 10 ms and refractoriness is 2 ms.
Synaptic decay is 3 ms, inhibition decay 5 ms, and adaptation decay 50 ms.
The last two mechanisms and gains are experimental choices, not physiological
parameter estimates. Use `CircuitConfig` to vary them programmatically.

Modes:

| Mode | Mechanism |
| --- | --- |
| `kwta` | Fixed excitatory projection, global exact top-k budget; deterministic ties |
| `ann-threshold` | Same projection with a fixed calibrated threshold |
| `threshold` | LIF PN/KC circuit without feedback or adaptation |
| `feedback` | LIF with finite graded feedback inhibition |
| `adaptive` | Feedback plus KC spike-triggered adaptation |
| `legacy` | Earlier signed Gaussian projection and separate per-stream k-WTA |

The common representations are `gray`, raw `colour`, simple `opponent`, `clahe`
and `apiaviz`. Fixed feature slots preserve PN/KC wiring across these conditions.
The CLAHE condition in the new runner is projected through KCs; the historical
runner retains the native 360-value CLAHE template baseline. Neither condition
alone is the full Ardin network.

Memory readouts are cosine templates, a single anti-Hebbian MBON, or a population
of MBONs partitioned by memory sequence. Flower reward choice uses a balanced
reward prototype update. These are associative learning rules. The initial
study reads spike activity through these shared analytical readouts; it does
not claim that every readout and controller operation is implemented in spikes.

## Calibration and experimental controls

Calibration chooses one threshold shared across both streams, matching mean
**total population activity** on development inputs. A fixed logarithmic grid
is followed by two local grid refinements; this does not assume monotonicity of
the recurrent circuit. The selected threshold, complete search and achieved
activity are saved. Matching may be imperfect, especially for tied/constant
inputs or missing colour; report the achieved test activity, not only the target.
Calibration is model tuning using unlabelled development data, not synaptic
training or evidence of a parameter-free model.

Navigation calibration uses ants 1–3 by default; evaluation uses ants 4–15.
Flower calibration images are removed before cross-validation and sampled across
classes. All fixations of an original flower remain in the same fold. Training
memory always uses clean images with an independently fixed exposure count,
including when test images are corrupted or the number of test fixations varies.

`--calibration-mode fixed` inherits thresholds from the unperturbed circuit;
`matched` recalibrates each intervention to the requested average activity.
Use both to distinguish causal removal from a change in total activity. Count
matching is not guaranteed by active-population matching: measured PN/KC spike
counts are also recorded. `--spike-readout early` means activity in the first
20 ms (or the full window if shorter); calibration still targets full-window
activity. `count` retains magnitudes and uses graded MBON memory.

`shuffle-times` applies a different fixed time permutation to each PN and
preserves every PN's spike count. It tests temporal structure while holding PN
rate information constant. It is a causal perturbation, not a physiological
input generator. `--persist-fixations` is an explicitly separate experiment;
training presentations remain independently reset.

The offline scan protocol probes centreline and ±0.2 m lateral positions. Since
scans are centred on the known heading, silent or completely flat responses are
scored as unresolved (180° penalty), with their count reported. Otherwise a
flat familiarity function could receive perfect accuracy from a centre-preferring
tie policy. During navigation, no-evidence responses continue straight ahead.

Reset and free navigation have identical action and memory budgets in the study
runner. Reset mode explicitly replaces off-route agents at the next waypoint;
teleportation is excluded from travelled path length and resets are counted.
This shared implementation is not byte-for-byte the historical Ardin controller;
`pixi run nav` retains the historical controller for reproduction.

Common-mode intensity noise preserves opponent differences only before clipping.
The study records clipping fraction and measured G−B change. Also include gray,
chromatic and independent sensor-noise conditions. Synthetic colour landmarks
and a shared simulated world limit generalisation claims.

## Running the planned panels

The complete factorial study is expensive. First inspect its encoder matrix with
`--list`; cap routes/steps explicitly for smoke tests and do not report those as
navigation success experiments. Each command creates a new timestamped run.

```sh
# Spatial/activity sparsity panel. All seeds, readouts and memory exposures are paired.
pixi run study --task nav --representations gray colour opponent clahe apiaviz --modes kwta ann-threshold threshold feedback adaptive --sparsities .01 .02 .05 .10 --seeds 7 8 9 --environment-seeds 99 100 101 --durations 20 50 100 --viewpoints 1 9 --protocols offline reset free

# Mechanism removals at the original threshold, then with matched population activity.
pixi run study --representations apiaviz --modes adaptive --perturbations none no-inhibition no-adaptation shuffle-times --calibration-mode fixed
pixi run study --representations apiaviz --modes adaptive --perturbations none no-inhibition no-adaptation shuffle-times --calibration-mode matched

# Sensory robustness and frontend ablations (repeat --ablate for each stage).
pixi run study --representations gray colour opponent apiaviz --modes kwta adaptive --conditions clean gray luminance chromatic noise --severities .5 1
pixi run study --representations apiaviz --modes adaptive --ablate opponency

# Secondary flower behaviour and few-example acquisition.
pixi run study --task flowers --representations gray colour opponent apiaviz --modes kwta adaptive --shots 1 5 0 --fixations 1 8 --training-fixations 1
pixi run study --task flowers --flower-task classify --representations apiaviz --modes kwta adaptive

# Temporal readout, integration and timestep sensitivity.
pixi run study --task flowers --representations apiaviz --modes adaptive --spike-readout count
pixi run study --task flowers --representations apiaviz --modes adaptive --spike-readout early
pixi run study --task flowers --representations apiaviz --modes adaptive --persist-fixations
pixi run study --representations apiaviz --modes adaptive --dt .5

# Reproduce the historical 8,000-total-KC code inside the new harness.
pixi run study --representations apiaviz --modes legacy --code-dim 8000
```

`--segments` controls MBON population capacity. Keep it fixed across
representations, and sweep it separately if memory capacity explains a gain.
The same applies to centreline versus nine-view corridor memory.

## Pretrained controls

Use official weights, never an untrained placeholder. Downloads are explicit;
the encoder requires local checkpoint paths and loads tensors with
`weights_only=True`. Keep downloaded assets under ignored `apiaviz/output/`.

```sh
mkdir -p apiaviz/output/checkpoints
curl --fail --location https://download.pytorch.org/models/mobilenet_v3_small-047dcff4.pth --output apiaviz/output/checkpoints/mobilenet_v3_small-047dcff4.pth
git clone https://github.com/facebookresearch/dinov2.git apiaviz/output/checkpoints/dinov2
curl --fail --location https://dl.fbaipublicfiles.com/dinov2/dinov2_vits14/dinov2_vits14_pretrain.pth --output apiaviz/output/checkpoints/dinov2_vits14_pretrain.pth

pixi run study --task flowers --representations mobilenet dinov2 --mobilenet-checkpoint apiaviz/output/checkpoints/mobilenet_v3_small-047dcff4.pth --dinov2-checkpoint apiaviz/output/checkpoints/dinov2_vits14_pretrain.pth --dino-repo apiaviz/output/checkpoints/dinov2 --deep-pooling global spatial --deep-sensory gb rgb
```

Both adapters are frozen. The controlled GB input reconstructs the missing red
channel from mean(G,B); the RGB condition uses native source channels. Inputs
are resized preserving aspect ratio, padded to patch multiples and never
centre-cropped, so the panorama remains visible. Global pooling is 1×1; spatial
pooling is 2×8. Both preserve signed deep features via positive/negative slots
for the common nonnegative memory interface. Deep descriptors retain native
dimensionality and use graded memories; they are performance controls, not
claims of matched KC count. Report descriptor dimension, checkpoint bytes and
timing alongside performance. The reported tensor size includes fixed buffers;
timings cover encoder processing, not rendering or controller costs. Spike
counts alone do not establish energy efficiency.

## Outputs, uncertainty and claim boundaries

The manifest contains CLI settings, package versions, revision, dirty-tree flag
and source hashes. Encoder files contain configurations, wiring, calibration and
fingerprints. Dataset splits and hashes identify actual inputs. Results include
code activity, memory collisions/overlap, PN/KC events for spiking models,
corruption diagnostics and task metrics. Traces retain complete familiarity
curves for offline navigation and trajectories/reset positions for moving agents.

Navigation summary intervals resample ants, preserving within-ant dependence.
Flower intervals resample image IDs, preserving all CV repetitions. Flower scores
are centred and scaled using only acquisition-fold evidence before combining
out-of-fold predictions. These intervals are conditional on fitted memories and
the selected reward assignment; they do not replace repeated splits, reward
assignments or environments. A single-ant experiment reports no between-ant CI.

Compare two encoder IDs in the same run with paired bootstrap draws:

```sh
pixi run python -m apiaviz.research.compare RUN_DIRECTORY BASELINE_ID CANDIDATE_ID
```

The comparison requires aligned episodes or image IDs. Report absolute AUC
differences and accuracy percentage points explicitly. Broad equality claims
need an equivalence margin; overlapping confidence intervals are not an
equivalence test. Heading/behaviour sensitivity under smaller timesteps needs a
full repeated study even though the unit suite checks elementary integration.

## Literature basis

- [Ardin et al., 2016](https://doi.org/10.1371/journal.pcbi.1004683): visual route memory, sparse KC expansion, one-shot associative memory and corrective resets.
- [Jesusanmi et al., 2024](https://doi.org/10.3389/fphys.2024.1379977): LIF visual mushroom-body navigation with feedback inhibition; important prior art.
- [Lin et al., 2014](https://doi.org/10.1038/nn.3660): feedback inhibition, sparse decorrelated representations and learned discrimination.
- [Papadopoulou et al., 2011](https://doi.org/10.1126/science.1201835): graded inhibition by a nonspiking wide-field interneuron.
- [Farkhooi et al., 2013](https://doi.org/10.1371/journal.pcbi.1003251): adaptation as a mechanism for temporally sparse sensory coding.
- [DINOv2](https://github.com/facebookresearch/dinov2) and [Torchvision MobileNetV3-Small](https://docs.pytorch.org/vision/main/models/generated/torchvision.models.mobilenet_v3_small.html): official pretrained implementations.

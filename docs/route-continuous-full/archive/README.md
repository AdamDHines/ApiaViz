# Cancelled run: compact archive

This is a byte-preserving copy of the frozen protocol, source-hash manifests,
cancellation record and completed summary rows from `route-continuous-full`.
There are 145 completed rows: 61 meander, 40 bend and 44 hairpin. The run was
cancelled on 30 September 2026 before collision-geometry fixes.

These results use conservative rock discs and are incomplete. Do not treat them
as confirmed physical contacts, a final baseline comparison or authorization to
resume. The cancellation record takes precedence over historical `running`
fields in the unmodified manifests.

Per-step trace paths in the rows refer to the original world output directories;
full traces, source snapshots, rendered images and checkpoints are not included
in this compact Git archive. Restore the ignored local output tree separately
for detailed replay. Absolute paths and hashes in protocols are historical
provenance and should not be edited to force compatibility with a new machine.
